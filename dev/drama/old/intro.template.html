Higgsfield
  • Bạn đăng nhập Higgsfield trong trình duyệt; Claude không đăng nhập hộ.
  • You sign in to Higgsfield in the browser; Claude never signs in for you.
  • Mỗi video tốn credit, nên Claude hỏi trước mỗi đợt (vd. 5 video × 4 giây).
  • Each video costs credits, so Claude asks before each batch (e.g. 5 videos × 4 s).
DramaClaw
  • Chạy trên máy: uv run novelvideo api --port 8780; Claude điều khiển qua MCP.
  • Runs locally: uv run novelvideo api --port 8780; Claude drives it through MCP.
  • Phần tự tạo ảnh / video của nó cần key trả phí, nên ở đây chỉ dùng làm kho dự án + canvas (upload ảnh không cần key).
  • Its own generation needs a paid key, so here it is only the project store + canvas (uploads need no key).
  • License Elastic 2.0: Greenbox chỉ gọi API, không chép code.
  • Elastic 2.0 licence: Greenbox only calls its API, no code copied.
Greenbox
  • Previz dùng nhân vật / xe đã rig: cùng một model cho mọi shot nên nhân vật không đổi mặt.
  • Previz uses rigged characters / vehicles: one model in every shot keeps the character consistent.
  • Bảng shot và nút “gửi sang Video FX” là bản demo trên trang này, chưa thành tính năng trong Cockpit.
  • The shot board and “send to Video FX” are a demo on this page, not yet a Cockpit feature.
